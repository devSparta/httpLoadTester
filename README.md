# gload

`gload` — небольшой консольный HTTP load tester, написанный на Go.

Программа отправляет заданное количество HTTP-запросов к указанному адресу, ограничивает число одновременно выполняемых запросов и после завершения показывает основные метрики нагрузки: количество успешных и неуспешных запросов, RPS, среднюю задержку, p50/p95/p99 и распределение HTTP-кодов ответа.

Проект предназначен в первую очередь для обучения Go и базового тестирования собственных HTTP-сервисов и локальных стендов.

## Требования

- Go 1.22 или новее.

## Запуск без сборки

```bash
go run ./cmd/gload -url https://example.com -requests 100 -concurrency 10
```

## Сборка

### Windows

Из корня проекта:

```bash
go build -o gload.exe ./cmd/gload
```

Запуск:

```bash
.\gload.exe -url https://example.com -requests 100 -concurrency 10
```

### Linux / macOS

Из корня проекта:

```bash
go build -o gload ./cmd/gload
```

Запуск:

```bash
./gload -url https://example.com -requests 100 -concurrency 10
```

## Параметры запуска

```text
-url          URL тестируемого HTTP-сервиса, обязательный параметр
-method       HTTP-метод, по умолчанию GET
-requests     общее количество запросов, по умолчанию 100
-concurrency  максимальное количество параллельных workers, по умолчанию 10
-timeout      timeout одного HTTP-запроса, по умолчанию 10s
```

## Метрики

**Requested** - сколько запросов было запланировано.

**Completed** - сколько запросов фактически завершилось и попало в статистику.

**Successful** - количество запросов без ошибки с HTTP status code `200–399`.

**Failed** - запросы с сетевой ошибкой, timeout, ошибкой чтения ответа либо HTTP-кодом вне диапазона `200–399`.

**RPS (Requests Per Second)** - среднее число завершённых запросов в секунду за всё время теста.

**avg** - средняя длительность одного запроса.

**p50** - 50% запросов завершились не медленнее указанного времени.

**p95** - 95% запросов завершились не медленнее указанного времени.

**p99** - 99% запросов завершились не медленнее указанного времени.
